GDoc Fixer — 한글 양식 자동 작성과 AI 문서 게시

한글(HWP) 양식의 서식을 그대로 둔 채 내용만 채웁니다. 표·글꼴·페이지 설정이 원본 그대로 유지되므로, 정부 지원사업 신청서나 사업계획서처럼 형식이 정해진 문서를 그대로 제출할 수 있습니다.

할 수 있는 일

  • 한글 양식 채우기 — 양식(.hwpx)의 단락과 표 구조를 읽고, 각 칸에 맞는 내용을 채워 넣습니다. 안내문이 적힌 칸은 무엇을 써야 하는지 알아냅니다.
  • 표 행 늘리기 — 양식의 데이터 행보다 항목이 많을 때 서식을 유지한 채 행을 복제합니다.
  • 문서·슬라이드 웹 게시 — HTML 문서와 슬라이드를 URL 로 올립니다. 링크를 아는 사람만 볼 수 있습니다.
  • 디자인 시스템 24종 — 슬라이드·문서 디자인 규칙을 AI 프롬프트에 그대로 넣을 수 있는 형태로 제공합니다. 내 브랜드 색으로 직접 만들 수도 있습니다.
  • HTML 문서 편집기와 AI 슬라이드 생성기 — 웹에서 직접 쓸 수 있습니다.

AI 가 직접 씁니다

Claude · ChatGPT · Gemini · Grok 이 사용자를 대신해 API 를 호출하도록 만들어졌습니다. API 키를 발급하고 아래 주소만 알려주면, AI 가 사용법을 스스로 읽고 씁니다.

  • /api/guide — 전체 사용법 (마크다운)
  • /api/tools — 도구 스키마 (Anthropic · OpenAI 형식)
  • /ai — 플랫폼별 연동 방법

Google 계정으로 로그인하면 바로 쓸 수 있고, 가입 시 무료 코인이 지급됩니다.
